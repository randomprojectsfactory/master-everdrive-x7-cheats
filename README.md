# Master & Game Gear EverDrive Cheats

Game Genie cheat menus for Master EverDrive X7 and Game Gear EverDrive X7. Final release. No Python or flashing required.

Choose the download for your cartridge: SMS has the original layout; GG has a compact layout for the smaller screen. The GG build was also tested with SMS ROMs on EDGGX7.

- [Game Gear EverDrive X7 — compact GG layout](https://github.com/randomprojectsfactory/master-everdrive-x7-cheats/releases/download/v12/EverDrive-Cheats-v12-GG.zip)

## Install

1. Download the matching ZIP and extract it.
2. Back up your SD card's SMSSYS folder.
3. With the console off, copy SMSOS.BIN and CHTEDIT.BIN from the ZIP's SMSSYS folder into the card's existing SMSSYS folder, replacing those two files. Create SMSSYS/CHEATS if missing. Preserve saves, settings and cheat files.
4. Safely eject and boot. Cheats is the third in-game menu option and is also available from a ROM's file menu.

## Uninstall

Restore your backed-up SMSOS.BIN or original SMSOS v1.04. You can then remove CHTEDIT.BIN. Keep SMSSYS/CHEATS to preserve your codes. No flashing required.
