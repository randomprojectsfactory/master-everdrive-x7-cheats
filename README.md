# Master EverDrive X7 Cheats

Game Genie cheat menu. **No flashing required.**

[Download v11](https://github.com/randomprojectsfactory/master-everdrive-x7-cheats/releases/download/v11/Master-EverDrive-X7-Cheats-v11-ready.zip)

Tested on a Master System Model 1 (USA) and a Japanese Game Gear via Master System Player.

## Install

1. Download and extract the ready-to-copy ZIP.
2. Back up the SD card's SMSSYS folder.
3. With the console off, copy SMSOS.BIN and CHTEDIT.BIN from the ZIP's SMSSYS folder into the card's existing SMSSYS folder, replacing those files. Create SMSSYS/CHEATS if missing. Keep existing saves, settings and cheats.
4. Safely eject the card and boot. Cheats is the third in-game menu option.

## Uninstall

Restore your backed-up SMSOS.BIN or the original SMSOS v1.04 file. You can then delete CHTEDIT.BIN. Keep SMSSYS/CHEATS to preserve your cheat entries. No flashing is required.
